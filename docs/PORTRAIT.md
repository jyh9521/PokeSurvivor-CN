# 手机竖屏适配（0.7.1）

## 行为

- 支持手机竖屏和横屏。移除竖屏遮罩与转向自动暂停；全屏不再锁定横屏，PWA manifest 的 orientation 为 any。切换方向只重算画布、镜头与触控布局，不新建玩家、房间或存档。切换应用仍保留原有暂停规则。
- 镜头横屏仍使用原来的 768 世界单位宽和最小 420 高；竖屏使用 480 世界单位宽，让角色不至于缩得过小。只改变视口，不修改伤害、移动速度、强化或奖励规则。
- HUD 的 layout() 同时供绘制和触摸区域使用。竖屏生命、计时、天气与 Boss 信息分层；招式在底部，道具与羁绊移到招式上方，避免四招式时道具出屏。暂停为 44px 触控目标；计算遵守安全区。旋转重置未松开的摇杆方向，避免残留移动。
- 菜单、图鉴、强化、抽卡、任务、好友、排行榜、设置、弹窗使用窄屏布局与可滚动容器。顶部账号栏分两行，长表格重排；技能卡片纵向排列，强化长按钮按内容宽度换行布局。输入框至少16px字体，降低 iOS 聚焦自动放大的风险。
- 团队标记在竖屏右侧排列，避开招式；延迟按钮在对局暂停键下方，菜单中则留在底角。公告仍不阻塞触控。

## 验证

`node --test tests/portrait.test.cjs`：相机横竖屏、HUD/安全区几何、横屏原始布局及 PWA 方向配置。

`node tests/portrait-browser.cjs`：真实 Chromium，移动设备/触摸仿真。覆盖 320×568、360×780、390×844、430×932；六个子页面、顶部栏、键盘收起前后的可达性；真实多点触控移动与第二指切招式、暂停、选卡；同一玩家的横竖屏切换与存档身份保留。

PowerShell：`$env:PS_PORTRAIT='1'; node tests/nas-browser.cjs`：复用现有双浏览器 NAS 联机测试，新增同房间旋转及团队按钮布局检查。此变量只影响测试，不进入部署配置。

PowerShell：`$env:PS_PORTRAIT='1'; npm run test:nas:production`：保护包和真实 Service Worker 的移动竖屏启动、账号存档、公告及手柄回归，检查真实加载的 PWA manifest。

保留原手柄和遮挡交互测试。源码 → 保护包 → SEO 页面 → 字体与 ZIP 可复现生成流程不变。账号/NAS挂载目录、数据库结构及 API 未修改。

这些检查属于浏览器仿真，不等同于实体 iPhone Safari、Android 浏览器工具栏与刘海安全区的设备验收。已安装的 PWA 是否及时更新 manifest 取决于浏览器，普通浏览器页面刷新即可读取新版。
