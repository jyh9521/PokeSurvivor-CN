# 0.16.0：特殊系统、阶段首领与御三家裂隙

## 玩家入口

- 图鉴详情中，已拥有且有完整素材的物种提供形态按钮。新增阿罗拉雷丘、黑夜/黄昏鬃岩狼人、现形谜拟丘、永恒之花花叶蒂和完全体基格尔德。选择形态后再点“选择为伙伴”，会随原物种编号保存，不占用新全国编号。
- 战斗仍然用 **C/R3切换特殊系统，V/L3发动**，或者点击现有按钮。学习新技能不会自动切换当前主动技能。
- Z招式由**当前主动招式**决定；切到合法前置招式才使用对应专属Z，否则使用该招式属性的通用Z。特殊框下方显示实际Z名称。
- 谜拟丘受到首次未被格挡或护盾完全挡住的伤害时会自动变为现形，单次伤害最多为最大生命的12.5%；本局画皮不重置。手动以现形出战则不再获得画皮保护。
- 一局仍然只能使用一次特殊系统，三选一：Mega持续30秒、普通极巨化20秒、或一次Z。死亡、结束、退出不会留下临时属性；普通极巨化会同步更新可见体型和碰撞体。
- 现有物种的基础形态选择采用本作拥有即选的适配规则，不声称复刻原作稀有个体获取流程。永恒之花与完全体切换是明确的形态入口，普通花叶蒂/普通基格尔德不能直接跳过形态条件发动Mega。

### 普通极巨招式适配

- 转换后的攻击伤害为基础招式的1.35倍，并扩大覆盖；不额外叠加旧版统一20%增伤。
- 火、水、岩石、冰等建立8秒个人领域，同属性伤害提高20%；火水领域对相反属性降低20%。领域效果不是覆盖全图天气，不干扰裂隙既有天气。
- 格斗/毒分别提供有限物攻/特攻加成，飞行提供机动加成，钢/地面分别提供物理/特殊保护；草提供少量恢复，妖精领域清除移动减速。
- 虫/龙分别提供特殊/物理保护，幽灵/恶分别增强物理/特殊输出；一般、虫、幽灵、龙、恶也会对附近敌人施加受首领抗性限制的减速。
- 特效效果共用2.5秒触发间隔，状态有时限、布尔加成不按命中次数无限叠层。极巨防壁为短暂减伤与一层格挡，不是对所有纯伤害永久无敌。

## 敌方治疗规则

1. 受疗者保存3秒锁，所有治疗者共享；计时跟随权威端模拟时间，不用现实墙钟，暂停不消耗冷却。
2. 每次恢复最大生命的5%，不再随玩家攻击倍率提高。
3. 治疗者不能治疗自身或其他治疗者；死亡、满血和冷却中的目标不占名额。
4. 每次最多4个目标，按生命百分比升序，同百分比按稳定敌人ID排序。
5. 所有Boss、传说/审判首领不接受治疗。客户端只显示房主结果，不独立回血。

## 多阶段常规Boss

当前配置：鬼斯→鬼斯通→耿鬼、拉鲁拉丝→奇鲁莉安→沙奈朵、可可多拉→可多拉→波士可多拉，以及飞天螳螂→巨钳螳螂、大岩蛇→大钢蛇。

- 只在全部阶段都有素材时选用；常规Boss时段中部分槽位抽取这些配置，不把所有Boss强制改成三阶段。
- 二阶段在50%生命切换；三阶段在2/3与1/3生命切换。共享一个生命池，不回满、不复活，不靠强制锁血惩罚高输出。
- 攻击组分别为突进/扇射、跳跃/落点轰炸、践踏/光束/环射，切阶段会更换整组攻击。
- 转场取消该Boss旧阶段的危险区域/子弹，保留其他敌人和新阶段预警；短暂停顿后再进攻。
- 同一敌人ID同步实际物种、阶段和体型，周期快照能修复漏通知；旧阶段快照不让形态回退。

## 御三家裂隙与成就

- 关都至帕底亚共27条三阶段御三家路线，基础形态→中间进化→最终进化，一次面对一条路线。
- **独立遭遇计时**：不替换原神兽候选池，不重置神兽概率保底计数。御三家裂隙使用单独标识，战斗结束沿用原来的回图/羁绊流程。
- 使用`starterBosses`记录，不混入`legends`。胜负消息绑定唯一竞技场ID；重复消息及上一竞技场的延迟消息均不会给新竞技场加进度、羁绊或错误结算。
- 27个单体成就各150金币，9个地区成就各2张单抽券；首次挑战1张单抽券，全员不倒2张单抽券，全收集2张十连券及称号。奖励无永久战斗属性，既有成就幂等逻辑保证一次领取。
- 图鉴原物种拥有权不会因击败普通御三家Boss直接被伪造为捕获。

## 新弹道与技能

种子炸弹为有飞行弧线和落点预警的投掷；龙箭单次分裂；魔法叶曲线推进；飞水手里剑有限跳弹；滚动为大判定滚弹；魔法火焰为螺旋推进。旧回旋镖、连锁、地雷、炮台、推进波浪等保持可用。

分裂弹子代共享命中排除集合，最多分裂一次；新弹道每名角色最多80颗、全局480颗。跳弹次数有限，不能靠贴墙无限重击同一敌人。投掷只在落点结算一次，主人死亡/切图清理；幽灵演出不结算伤害或恢复。特效质量只影响表现，不改变命中和伤害。
