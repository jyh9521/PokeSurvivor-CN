# 0.16.2 第二轮：近战生存、落点技能与重击

## 修改范围
本轮不改敌人生命曲线、等级成长、本系倍率、精通、物种六维和普通被动槽位。只调整近战接触生存、岩石/冰雨类落点、寄生种子以及两种重击。

### 近战保护
- 主动槽包含近战，或处于已确认近战命中的保护延续期时，普通身体碰撞采用40%减伤，单次损失最多22%最大生命，实际受伤后获得0.6秒共享受击间隔。
- 单次上限在防御与减伤之后、护盾吸收之前计算；不把护盾按未封顶巨额伤害扣除，也不为每个敌人单独开免伤计时器。
- 原有25%近战减伤继续用于其他非纯伤害，不与40%重复叠乘。已有格挡、闪避、护盾和防御被动保留。
- 上限只针对普通碰撞。冲锋、跳跃、正在施放的首领技能、审判者不使用此保护；光束、落点危险区域与纯伤害不封顶。预警区域保留原有强制结算机制，不能靠身体接触后的保护硬吃预警攻击。
- 敌人快照状态位16同步“非普通接触状态”，客机不会把冲锋错误当作普通碰撞；协议升级8隔离旧客户端。
- 撞击命中后的保护延续0.6→0.8秒，普通怪硬直0.15→0.20秒；共享硬直冷却仍0.65秒，精英减半、首领免疫，不形成无限控制。

### 重击
- 泰山压顶在0.16.1基础上单次伤害×0.78，基础覆盖半径×1.15，普通怪硬直0.25秒。
- 嬉闹单次伤害×0.72，保留原有较长冷却和较大覆盖。
- 两者在同升级状态下，单次伤害保持高于撞击、低于两次撞击；不是削到没有优势。快攻负责连续输出，重击保留范围和时机价值。

### 落点与恢复技能
- 陨石类（岩崩、冰雹、彗星拳）基础伤害×1.35、范围×1.15，落下时间0.50→0.35秒，批次间隔0.09→0.04秒。
- 开始0.18秒跟随选定目标，之后冻结显示的落点，不无限追踪、不在命中瞬间传送。目标死亡则保留最后落点。
- 目标少于落点数时重复分配给可用目标，但同一施放批次对同一个敌人最多命中两次。不同施放有独立预算，防止对大体型首领无限叠所有落点。幽灵演出不消费预算、不产生伤害。
- 寄生种子：延迟1.10→0.55秒，基础范围60→76，伤害×1.15，恢复0.8%→1.2%最大生命。开始0.20秒短暂跟随目标；既有每秒4%共享恢复上限不变。
- 所有成长倍率只在定义构建时应用一次，不在每帧重复放大。

## 动态基准
工具：`tools/measure-dynamic-combat.cjs`，夹具：`tests/dynamic-combat-fixture.cjs`。

每个版本93个普通伤害招式×3个场景×3个固定随机种子，共837组；不是静止靶。基准实际运行Player.update、EnemyMgr.update、碰撞与敌人分离、近战控制、投射物扫掠、持续场地、Boss AI/阶段和Hazards。

场景为：
1. 移动追击：普通怪642生命、85速度，玩家接近/绕行，满级并在可用时进化。
2. 被包围：12只相同普通怪，3级招式、无进化；玩家前1秒停留，然后向外脱身。该压力测试要求脱身，不把远程站在包围中心存活当成合格条件。
3. 三阶段Boss：10000共享生命、75速度、65基础伤害，鬼斯→鬼斯通→耿鬼，玩家按可见预警选择闪避。另有不躲避负面用例证明保护不等于无敌。

统一41级喷火龙，不加防御被动、道具、羁绊或特殊形态，普通匹配设为中性以隔离技能机制；空旷场地、不补怪、不回满、不冻结、不强行重置每帧位置、不设置调试无敌，保留正常受击保护帧。死亡、未击杀和未清场均保留在结果中，不把它们删除后再统计。

固定种子1的例子（并非实战胜率）：
| 条件 | 0.16.1 | 0.16.2 |
|---|---:|---:|
| 撞击，包围脱身后的生命 | 8.30 | 58.80 |
| 岩崩，移动追击击杀秒数 | 1.717 | 1.433 |
| 冰雹，移动追击击杀秒数 | 1.467 | 1.350 |
| 寄生种子，移动追击击杀秒数 | 3.200 | 0.533 |
| 泰山压顶，Boss击杀秒数 | 8.667 | 11.000 |
| 嬉闹，Boss击杀秒数 | 10.167 | 13.767 |
| 冰雹，24秒Boss伤害 | 6960 | 9956 |

包围测试不是清场成功：撞击活着脱身，但没有杀光全部12只。远程落点技能仍不适合被12只怪围住后站桩；本轮没有让所有技能获得近战保护。部分技能仍未在24秒内击杀首领，完整结果全部保留。本轮证明定向改进，不证明93个招式同强度。

真实Chrome浏览器另跑移动怪、12怪包围和三阶段Boss，使用真实场地、碰撞与属性表。一般系对幽灵仍按本作0.3倍的强抗性处理；Boss场景使用恶系咬住，不为了过测试取消属性修正。浏览器自动驾驶和离线场景不能冒充实际玩家长期胜率或物理设备验收。
