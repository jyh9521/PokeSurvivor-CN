原作六维、属性和本家特性取已有锁定的 PokeAPI 表。生命、移速、攻击倍率沿用现有折算和稀有度阈值，不给新增伙伴额外数值优待。技能池是本作幸存者适配配置，每种12招，不声称全部属于原作可学招式。初始招式为显式开局配置，并经过优势攻击能力检查；被动、六维防御、Z招式和极巨化继续使用现有系统。

## 再现

1. `python -X utf8 tools/generate-battle-data.py --download` 恢复已锁定的本家数据缓存。
2. `python -X utf8 tools/import-catalog.py` 下载并核验固定修订的这9种素材，逐帧验证尺寸、八方向和时长，保留旧物种行。
3. `python -X utf8 tools/generate-battle-data.py` 按新增条目的 battleId 生成实际形态六维、特性与原作招式来源。
4. `python -X utf8 tools/make_zh_font.py`，随后 `node tools/build-local.cjs`。

导入器支持重复执行，缓存和锁定源哈希不符即失败。SpriteCollab里的Attack可以映射到真实Swing/Shoot；待机不被当作真实攻击。旧的通用全量导入器仍采用较严格的默认根目录筛选，运行它们后应按上述顺序再次执行本增量导入器。

旧966个物种记录、六维、ID与存档键保持原样，新增只扩充候选池。地域和混合扭蛋沿用原概率、票价和各池独立保底。更新后所有联机成员刷新页面，避免旧客户端缺少新增素材。
