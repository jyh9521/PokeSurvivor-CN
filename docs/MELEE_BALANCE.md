# 0.11.0 近战增强

所有调整均相对于 0.10.0 已有的近战强化，不修改账号、钱包、挑战奖励或存档格式。

## 公共规则

- 伤害乘 1.20、冷却乘 0.90、半径乘 1.15、基础弧度加 30°；重击和藤鞭另有下表加成。
- 非特色加成的理论伤害/秒提高约 33.3%；实际伤害仍经过取整、属性、天气、暴击及命中覆盖计算。
- 发动与命中共用半径，并计入目标身体圆。扇形边界采用圆与扇形的实际交集，取消原来额外 30 单位发动距离。
- 优先瞄准近战可命中的贴身威胁、可命中首领、最近可命中敌人，最后考虑范围内可破坏物。
- 保留主动技能组含近战时的 25% 减伤。实际扣除敌人生命后刷新 0.6 秒护体，切换远程仍有效；两者只计算一次。纯伤害保持原行为，不受护体减免。
- 普通敌人硬直 0.15 秒，精英减半；首领、传说和审判单位免疫硬直与近战击退。精英包含显式 elite 标志、闪光和黄金敌人。
- 每个敌人共用 0.65 秒硬直触发间隔，八名玩家不会分别拥有免控计时。硬直期间停止 AI、移动和接触伤害，异常状态计时继续。
- 每个敌人共用 0.35 秒近战击退间隔；单次冲量最多 45、触发后的总击退速度最多 60，避免多名玩家叠加击退。
- 基础技能保持扇形。原有满级与进化的 360° 升级仍保留。

## 技能特色

| 技能 | 公共强化之外的效果 |
|---|---|
| 撞击 | 伤害再乘 1.10、弧度再加 0.20 弧度 |
| 泰山压顶 | 伤害再乘 1.10、弧度再加 0.30；普通敌人硬直 0.22 秒 |
| 藤鞭 | 半径再乘 1.18、弧度再加 0.35 |
| 翅膀攻击 | 二连击；命中后移动速度 +12%，持续 0.6 秒，不叠加 |
| 金属爪 | 二连击；目标承受近战伤害 +15%，持续 2 秒，不叠加；生效后的后续攻击享受加成 |
| 虫咬、咬住 | 本技能实际击杀回复最大生命的 1%，两技能共享滚动一秒内最大生命 4% 的回复上限 |
| 空手劈 | 对精英和首领伤害乘 1.30 |
| 舌舔 | 减速 55%；普通敌人硬直 0.20 秒，仍受共享免控间隔限制 |

二连击将一次攻击的伤害分成 55% 与 45%，第二击延迟 0.09 秒。第二击不额外消耗生命宝珠、不重复施法；死亡、场景清理或所属玩家清理会取消待执行攻击。每击分别取整。

## 联机结算

敌人的扣血、死亡、破防、硬直和击退仅由敌人权威端（房主）处理。队友的 ghostCast 只播放特效，包括第二段连击。

近战消息 `mh` 携带本局递增序号、目标、伤害、方向、技能 ID、等级与进化状态。房主按成员维护已处理序号；重复序号不再结算。房主只给实际造成生命损失的发送者返回 `mb` 回执，其中包含实际伤害与击杀结果。只有这份回执可为访客触发护体、机动、伤害回调和击杀回复；访客也去重回执。不存在本地预判击杀回血，其他队友攻击已死亡目标也没有回血。

硬直状态通过现有敌人快照的 bit 8 传递，访客的接触伤害判定也尊重该状态。沿用现有可靠传输和八人 10Hz 上限；没有增加逐帧控制消息。伤害仍来自现有客户端模拟，这不是服务器反作弊验证。

## 复现验证

在仓库根目录运行：

```sh
node --test 'tests/*.test.cjs'
node tests/melee-browser.cjs
PS_RELAY_ONLY=1 node tests/melee-browser.cjs
npm run build
node tests/nas-production.cjs
node tools/verify-melee.cjs
```

浏览器用例复用现有挑战/存档/排行榜/八人联机验收，并在八个真实浏览器间加入实际近战攻击、房主确认击杀、回执回复、切换护体、共享破防、击退限速和控制结束检查。受控敌人用于可重复命中测试，不等同于长时间玩家手感或公网延迟验收。

事务脚本保存原始哈希、完整基线归档、修改快照、补丁与全部日志，并仅在带标记的隔离副本内验证回滚；主目录保持新版。运行环境需要 Node 24、已有 node_modules，以及 Git Bash（Windows 可通过 BASH 指定路径）。

## NAS 更新

游戏内开启维护并等待“已排空 / 可更新”，随后在 NAS 终端直接粘贴：

```sh
(
set -e
WORKDIR="$(mktemp -d /mnt/user/appdata/pokesurvivor-update-XXXXXX)"
git clone --depth 1 --branch main https://github.com/jyh9521/PokeSurvivor-CN.git "$WORKDIR"
cd "$WORKDIR"
sh deploy/update-unraid.sh 'https://pokemon.blfy.cc:9521'
)
```

更新成功后手动“重新开放服务器”并刷新客户端。更新脚本沿用原数据库挂载并先备份数据库；本次发布不改变部署脚本或数据库 schema。
