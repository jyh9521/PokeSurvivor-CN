# 0.16.6：玩家反馈修复、手柄成长与完整帧性能

## 审计与复现

基线是0.16.5 `fbc151a1d934352019e92267f494c8de8853730f`。本轮先运行284项基线测试，再新增三项回归，原版0通过、3失败后才修改。截图是玩家症状证据，不是开发指令。既有档案、原作六维、近战接触保护、四主动/四被动槽、羁绊融合、裂隙及三类特殊招式保留。

### 1. 精通点不是手柄操作错误

原版实际Chrome+USB输入复现：已进化招式、持有1点，Start打开的焦点所有者是`scr-pause`；其中精通按钮数0，而浮动区域有1个按钮。手柄在战斗中并不导航这个浮动区域，所以点数很容易一直等着。

新版把分配放到暂停菜单内：Start暂停，方向键选择具体招式实例，A/×确认。每次显示基础威力前后差值；总点数、已用点数、技能组、每招层数和不合格原因均可见。点数仍由唯一野外首领/成功裂隙获得，每招3层、每层+3%、全局6层，不自动消耗或错发至另一组。原始复现见本地`artifacts/feedback-0166/baseline-controller.json`，新版真实手柄导航见`release-feedback-browser.txt`。

### 2. 进化规则有定义，却被资格和抽卡双重锁死

审查发现93种常规攻击都有进化定义。真正的问题是四被动槽不包含前置且重抽耗尽时没有修复通路，随后事件精通也因为没有进化目标而一直挂起；合格进化卡还可能被大量候选稀释。

新版：招式升至最高等级后，已有前置被动仍可提前解锁；玩家12级的战斗经验也可替代缺失被动前置。只要存在合格进化，三选一至少有一张进化卡（多个合格目标之间随机）；仍需本人选择，不自动进化、也不消耗精通点。93/93常规攻击通过“四错误被动、无重抽”的实际卡片执行测试。特殊形态专属招式不冒充普通升级招式。

### 3. 成型后还有明确、有限、可选择的伤害成长

进化后增加招式实例绑定的“研修”：从玩家12级起每4级开放一层，每次消耗一次正常升级奖励，单招最多12次。每层+5%本招伤害，同一来源加法，总计+60%，不增加弹幕数量或无上限复利。进化、精通、研修分别标识；不强制用新招式占掉成熟构筑。玩家等级原有4.5%输出成长保留。

研修不只改显示：普通直射的投射物payload、持续轨道弹与近战房主结算均覆盖，客机近战事件带有有界研修层数，房主仅结算一次，重复消息不叠加。新回归验证实际敌人扣血、旧卡重放失败与上限。升级卡和暂停清单显示单次基础威力、弹数与冷却，明确不含玩家属性、属性克制及敌方防御。

### 4. 大厅替代好友与统一游戏中状态

主入口改为大厅，显示全部在线账号（包括自己）。没有好友申请、增删或好友筛选入口；旧好友HTTP写接口返回410，既有数据库关系不删除，不迁移或重置账号存档。邀请不再依赖好友关系。

房间“邀请”跳转大厅，可连续邀请。空闲在线玩家直接收到醒目、手柄可达的确认弹窗；拒绝后可再邀，保留3秒同目标防连点和每分钟频率预算。本人、同房间、离线、游戏中、已满或关闭房间均禁止邀请，服务端再次校验接受邀请时的状态。

在线与游戏中分开：服务器以真实单人run及联机run/房间阶段计算状态，开始/结束时推送。大厅、房间、排行榜和资料页显示`■ 游戏中`，黄色方块；不把单人对局误判为空闲。排行榜继续有10秒静默刷新。双浏览器验证无好友组队、房间跳大厅、即时弹窗、拒绝再邀和正式联机。

### 5. UI、危险可读性和性能

特殊招式使用后的长状态独占整行；说明固定在第四行，防止隐藏能量条后自动排版挤入3像素网格。桌面真实布局与截图验证通过。

自己的弹幕20%/55%/100%，队友20%/40%/70%/100%，分别本机保存、直接按钮选择。友方区域采用青色虚线和三角标记；敌方保留红/橙实线与警示十字、感叹号，危险层绘制在友方区域之上，不受透明度设置影响。波次压制首次30→20秒、普通间隔24→16秒、压力段12→8秒、半径38→68、预警1.5→1.8秒，伤害及场景预警预算不加码。

低画质不再只是少几个粒子：内部渲染比由最高1.5降至0.75，极低为0.6，游戏世界/碰撞/触摸仍用CSS逻辑坐标；HUD在低画质复用20Hz绘制缓存，旋转精灵使用最多256项缓存，缩减装饰粒子、低画质水面闪光与全屏渐变，裁剪离屏装饰。焦点层缓存、手柄提示最多10Hz，保留实际输入轮询和战斗模拟频率；自动画质跨档时同步更新画布。敌方预警、有效弹幕、碰撞和敌人64上限不被裁减。

## 实测迭代：没有把拖长回归留在报告

加入研修后的第一轮九局全部存活，但防御种子17末位首领TTK达到309.80秒、最大命中空窗94.80秒，未通过240秒上限。单纯把反击窗口2秒改为4秒仍需259.17秒，因此该候选已撤销。

记录10秒位置/AI状态后发现首领被支援群追逐带到800单位追击范围外，距离一度超过2000；慢速首领一直正常步行，无法接近高速玩家，反击窗口再长也无效。最终保留原2秒反击窗口和所有首领HP/伤害，只在野外首领距玩家超过500单位时增加有界回场步速（最多×3）；500以内、裂隙、审判均不变。不增加伤害、瞬移或无预警落点。定向复测该局末位首领133.34秒，最大空窗19.53秒，然后才重跑全部九局。
