# 鼠标点击移动（0.7.2）

默认开启，设置 → 操作 → 电脑 → 鼠标点击移动可关闭；设置仅保存在当前浏览器。

- 左键点击地面：朝固定的世界坐标移动，到达后停止。镜头跟随不会把一次点击变成持续追逐。
- 按住左键：每150ms最多更新一次指针目标，跟随光标；松开后走到最后一个目标。右键取消。
- 键盘、手柄方向或触屏摇杆立即接管，旧鼠标目标清除。移动仍走原 Player.update、速度、碰撞、冰面惯性及联机同步逻辑；自动攻击不变。
- HUD 招式按钮优先使用原点击处理，不被误当成地面；菜单、确认框、暂停、选卡、死亡、裂隙场景切换、窗口失焦、缩放和视口切换取消目标。恢复后不续走旧目标。
- 淡金色小圆环标示目标。UI 文案使用现有本地化机制，手柄和触屏原提示保留。

## 实现

ClickMove 管理本机鼠标意图，通过 Input.axis(dt) 输出原有移动向量，不能绕过正常速度和碰撞。worldPoint 使用 Canvas CSS 坐标与相机逆变换，考虑像素缩放和相机震动。按键/摇杆手动移动先于鼠标目标。

在既有 Path 模块增加独立 route()，不改敌人距离场及其更新频率。优先使用无障碍直线，否则在当前位置57×57格范围内搜索，禁止斜穿封闭角；复用 World.walkable 与对临时坐标执行的 World.collide 进行实际身体半径检查，避开墙、实心物体和危险液体。结果按可见直线简化。最长350ms检查一次路线，连续650ms无进展即停；不可达目标给出反馈，不穿墙，也不承诺地图任意远端的长程导航。

鼠标状态本机独立，账号、存档、好友及联机协议不变。联机仍发送原有玩家移动状态；并未添加从网络直接指定其他玩家目标的接口。

## 验证入口

- `node --test tests/click-move.test.cjs`：障碍、身体半径与封角、搜索边界、到达停止、暂停和玩家替换清理、三种手动输入接管。
- `node tests/click-move-browser.cjs`：真实 Chromium 鼠标点击、按住、右键、键盘接管、HUD和弹窗隔离、可关闭设置及目标到达。
- PowerShell：`$env:PS_CLICK_MOVE='1'; node tests/nas-browser.cjs`：真实双客户端认证 NAS 联机，由客机鼠标点击移动并在房主观察到位置变化；其余联机回归沿用。
- `npm run test:nas:production`：受保护包、不暴露G；拦截原生Canvas绘制，确认实际地面点击产生目标标记、右键移除标记。另保留生产账号、存档、Service Worker 和手柄测试。
