# 社区版 0.4.1：操作、画质和队伍管理

## 抽卡与低配画质

抽卡界面的“跳过抽卡动画”按设备保存在 `ps.settings.skipGacha`。
开启后不运行老虎机、不等待逐张揭示，也不让结果精灵动起来；一抽或十抽直接一次显示全部结果。
抽取概率、保底、重复补偿、扣券和保存逻辑不变，关闭开关恢复原动画。

“设置 → 画面 → 低配画质”与旧的低画质分开：内部像素比固定为 1，纯视觉粒子上限 80、精灵特效上限 35、文字特效上限 8，关闭普通伤害数字、减少震动和闪光、取消天气粒子。
敌人数、攻击判定、危险区域预警、天气伤害、拾取、掉落和同步频率不变。
自己的轮廓仍显示。恢复其他画质后可单独打开伤害数字与震动设置。

## 房间准备和邀请

当前人数上限仍是 **4 人**。房主也要点准备，所有成员在线且准备后才能开始；后端 `/api/room/open` 同样检查，旧界面或直接请求无法跳过准备。
新成员加入、换伙伴、重新开放大厅、断线和大厅转移房主会清除相应准备状态。
所有房间成员均可邀请自己的好友。加入后仍使用原房间 ID，不替邀请者新建房间；邀请者离开、房间关闭或满员后邀请失效。

## 房主转移（仅大厅）

0.4.1 移除了对局中的房主转移入口和交接协议，后端同样拒绝对局内的转移请求。旧客户端发送交接消息也不会冻结或切换房主，不再加载对局迁移模块。
大厅房主仍可把身份交给在线成员，原房主留在房间，全队重新准备；大厅房主断线超过 30 秒宽限期时仍自动接任。对局内沿用短暂断线重连，超时退出，不做自动迁移或旧检查点恢复。

## 紧凑联机 HUD

- 集合／求救／危险改为与技能栏一致的深色半透明小控件，复用游戏像素图标和字体；位于左上队友生命栏下方，不再显示大块蓝底面板或重复生命列表。
- 保留 R / F / T、手柄、鼠标与触控操作，3 秒冷却不变。只有队友倒地时显示一行救援进度。选择、暂停或设置界面不覆盖这些按钮。
- 场景标记改为 16 像素图标与小型底衬，保留名称和离屏方向箭头，移除大圈。
- 右上仅显示信号条和毫秒数（优先房间 RTT，尚无房间样本时使用浏览器到 NAS RTT）；绿 / 黄 / 红表示延迟区间，点击才展开完整诊断，导出功能保留。
- 延迟标位于天气及触控暂停按钮下方；紧凑菜单中不遮挡设置按钮。

## 角色可见性

默认在树木、敌人和天气覆盖后重新绘制自己的半透明精灵及白色轮廓、黄色脚下标记。
只有自己的角色使用前景强调，队友维持原颜色与方向提示。设置 → 画面可以关闭。
未修改实体碰撞、攻击范围、地形遮挡规则或敌人行为。

## 手柄

调研过 [GameController.js](https://github.com/alvaromontoro/gamecontroller.js/) 和 [HTML5 Gamepad Controller Library](https://github.com/kallaspriit/HTML5-JavaScript-Gamepad-Controller-Library)。
本游戏只需标准布局、菜单焦点和少量动作，采用独立的 `js/core/gamepad.js` 直接接入浏览器 [Gamepad API](https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API)，无需 CDN 或第三方运行时。

- 按下并松开任意按钮识别手柄；支持浏览器 `mapping=standard` 的设备。
- 左摇杆 / 十字键移动，摇杆死区 0.2，斜向不加速。
- A / 下方主按钮确认；B / 右方主按钮返回；LB / RB 切换招式；Start 暂停。
- 联机时 A 集合、X 求救、Y 危险；菜单用方向键 / 摇杆导航，可操作卡牌、复选框和下拉选项。
- 长按按钮不重复购买；方向导航有 350 / 150 ms 的重复节流。断开、禁用或页面隐藏时清除输入，避免持续移动。
- 文字输入框保留键盘操作。非标准布局不猜测按键；可使用平台的标准手柄映射。
- HTTPS 下使用；浏览器首次音频解锁可能仍需要一次鼠标 / 键盘操作。

自动测试使用真实游戏加可控的标准 Gamepad 数据，覆盖移动、暂停与返回；不是 Xbox / DualSense / Steam Deck 的实物验收。

## 一键强化与返还

“一键最大强化”作用于当前选中的宝可梦：反复购买最便宜的可用下一阶，直到满级或余额不足。价格单调递增，因此此策略最大化可购买的等级数；同价按 ID 稳定排序，没有随机偏好。
“一键返还全部强化”需要确认，作用于所有宝可梦，按每阶实际价格表累计全额返还，清除相应禁用招式选择，保留收藏、绑定、资料、成绩、抽奖券和福利收据。
未识别的旧存档字段保留，不给未知强化虚构退款。

NAS 模式由 `/api/upgrades` 在服务器读取当前存档、计算并原子写入；修订号冲突被拒绝，重复返还的金额为零，对局内不能修改永久强化。
本地模式使用同一个 locale-neutral 计算模块，在浏览器保存。操作期间禁用强化按钮，异步期间发生其他存档修改时保留两份进度，不静默覆盖。

```sh

git pull --ff-only origin main && \
sh deploy/update-unraid.sh 'https://pokemon.blfy.cc:9521'
```
