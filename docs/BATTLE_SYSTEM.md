# 0.12.0：六维、物种身份与完整构筑

## 数据与存档

- 966 个可玩物种全部保留 HP、物攻、物防、特攻、特防、速度六项原始种族值。
- 数据来自 PokeAPI 固定版本 `81d20919845b6a445969b9265aab5cec6b04cece`，输入文件逐个校验 SHA-256。运行时不访问外部数据接口。
- 生命和移动速度沿用原换算及永久强化；物攻、特攻分别参与对应攻击，物防、特防分别参与承伤。
- 原招式 ID 不改。`leaf-storm` 在本项目显示为落英缤纷，因此学习表和伤害分类对应 `petal-blizzard`；`giga-drain` 显示为打草结，对应 `grass-knot`，而不是按历史 ID 误判。
- 新系统只写入本局 Player 状态，不增加账号、钱包、领取回执或持久存档字段；图鉴编号、异色归属和已有强化不迁移。

重建离线数据：

```sh
python tools/generate-battle-data.py --download
```

已有正确缓存时只校验并重建；缺失缓存从固定版本下载，哈希不符即停止，不使用运行时联网兜底。

## 物种身份与技能池

每个物种组合：六维倾向、实际第一特性来源、本作适配特性效果、进化家族学习表、定位技能。

特性分为坚甲、灵壁、绝境坚守、技巧、逆境爆发、本系适应、疾足、生息、凝神、蛮力、威压和战斗守卫。已有明确对应的特性按分组适配；其他特性按六维定位提供本作效果。图鉴明确区分“物种特性来源”和“本作效果”，不宣称逐字复刻全部原作特性。

技能池优先本物种学习表，其次同进化家族，再加入少量定位与通用补盲，每只提供 12～18 个攻击候选。学习数据合并多个版本，属于本作生存玩法的适配池，不是特定世代的对战合法性检查。

当前有 73 个可入池攻击定义、12 个独立被动定义、1 个仅供特殊强化的 Z 攻击定义。另保留 5 个旧 buff 定义用于历史数据/源码兼容，不再占用新攻击卡池。新增或重做的机制包括：

- 推进波：连续移动，使用扫掠碰撞，每个敌人每段只命中一次。
- 延迟印记：记录目标地面坐标，预警后引爆，不无限追踪移动目标。
- 反击：受伤或格挡后触发，拥有冷却，受物防与复仇被动增益。
- 替身：自动召出临时诱饵，吸引敌人，持续结束后爆发；每人最多一个有效替身。

主攻击仍通过原技能组切换；学会的反击与替身会在后台自动支援，不需要切过去，也不会因同时处于主技能组而执行两次。

## 被动、防御与结算

四个独立被动槽位，每项最多三级，不占四个主动招式槽位。包含：变硬、光墙、影子分身、守住、聚气、剑舞、冥想、扎根、水流环、铁壁、高速移动、复仇。

- 物理/特殊护甲减免：`armor / (armor + 180)`，本层上限 65%。
- 护甲与既有减伤、近战保护乘算；整体减免上限 85%，不是直接相加。
- 闪避总上限 30%，先于格挡和护盾；闪避不消耗格挡或护盾。
- 守住每 10/8/6 秒补充一层格挡，最多一层，不积攒。守卫特性本身的间隔为 12 秒，与守住不分别叠层。
- 铁壁每 8 秒刷新每级 5% 最大生命的护盾，不逐次累加。
- 暴击总上限 60%；物理与特殊攻击被动分别生效。
- 扎根只在静止时回复；水流环和生息独立提供持续恢复。
- 种子命中回复采用滚动一秒 4% 最大生命的共享上限；零实际伤害、重复回执、死亡角色不产生回复。
- 纯伤害绕过闪避、格挡、护甲、护盾和近战减免；阿尔宙斯原有纯伤害继续保留。

原有敌人接触攻击归为物理，能量弹幕与区域技能默认特殊，攻击定义可通过 `damageClass` 显式覆盖；不依据属性简单猜测物理/特殊。原有持续异常伤害规则保留。

## Mega、Z 招式、极巨化

每局共享一次特殊强化选择，不允许先 Mega 再 Z 或叠加极巨化。

能量每秒增长 0.8，实际直接伤害每次最多补充 1，直接击杀再补充 1，最多 100。满能量后方可发动。

| 选择 | 本作效果 |
|---|---|
| Mega | 符合条件的物种切换默认 Mega 的真实六维、属性和适配特性，持续 30 秒 |
| Z 招式 | 一次 220 范围、90 基础伤害的爆发；仍经过能力、属性、天气、暴击和护甲结算 |
| 极巨化 | 持续 20 秒，临时生命提高约 50%、伤害提高 20%、招式尺寸提高约 35%，角色图像放大但碰撞圆不放大 |

85 个可玩物种具有至少一份 Mega 数据，本版选择各物种的默认 Mega 记录。44 套完整 SpriteCollab 形态动画已单独导入并保存原作者署名；没有完整动画的形态使用原角色动画、缩放和独立变身光效，不冒充已补齐全部形态美术。异色收藏仍属于原物种，不生成或赠送额外收藏。

极巨化开始和结束保留生命比例，不通过切换凭空回血。到期、死亡或结束对局均恢复；重复结束不会再次扣除临时生命。普通图鉴编号与受击范围不改变。

战斗 HUD 使用蓝色双边框、像素字体与金色选中边框。特殊强化通过并排按钮直接选择，不打开下拉菜单；鼠标或触屏选择后释放按钮焦点，方向键继续控制移动。框内常驻两行按键用途说明：`C / R3：切换招式`、`V / L3：发动`；竖屏同样显示。

电脑：`C` 切换选择、`V` 发动；标准手柄：`R3` 切换、`L3` 发动；触屏点击对应选择与按钮。暂停、选卡、道具及融合界面不会通过快捷键误发动。

## 特效与联机

Canvas 2D 分层特效模块拥有按招式选择的喷流、分叉雷电、落雷、叶刃、旋涡、冰晶、种子、爪痕、上下颚、心形回复、地裂等表现，不引入外部 CDN 或 WebGL 引擎迁移。

特效与碰撞分离，有独立数量上限和低画质预算；队友特效降低不透明度，减少特效不改变伤害。地面印记保留预警。

新联机协议为 **5**，旧协议的新建/加入请求返回刷新提示，避免同房混用不同战斗规则。

- 房主决定敌人真实扣血、死亡、控制和诱饵目标。
- 普通攻击使用 `bh/bb` 递增序号与确认回执；近战保留 `mh/mb` 并支持反击。
- 角色只根据房主确认的实际伤害获取命中回复和能量；消息重放不会重复发放。
- 形态、剩余时间、护盾、格挡和四个被动等级随原角色快照传输。
- 招式事件携带目标坐标，保证队友延迟印记显示在对应位置。
- 纯视觉 ghost 不造成伤害或回复。访客替身必须经房主认可才进入房主的 AI 目标；房主的诱饵副本不重复爆炸伤害。

沿用当前客户端模拟和房主权威模型，不声称新增了完整的服务器反作弊模拟。

## 图鉴

关都左侧的“全部”显示 966 个物种。获取状态、18 种属性、异色/五档稀有度彼此独立，组合条件使用 AND；“全部”筛选按钮清除下方筛选与搜索，不擅自改变已选地区。

搜索覆盖名称原文与译名、属性、地区中英文、全国编号、种族值、身高体重、特性及招式等展示信息。空格分词使用 AND；`#025` 或前导零编号按精确编号匹配。普通文本会匹配所有索引字段，需要精确限定属性时使用属性选择器。输入只作文本，不解释为 HTML。

图鉴动画按可视区域延迟加载，避免“全部”一次启动 966 套动画。桌面搜索框在筛选右侧；竖屏自动换行。
