# 多设备、维护与团队战报（0.8.0）

## 管理员与更新

唯一管理员是不可修改的登录账号 `jyh9521`，不是公开昵称。其他账号即使
伪造前端属性或直接调用接口，也不能读取管理状态、开启维护或紧急更新。
入口：设置 → 账号 → 服务器管理。管理员接口使用同源会话与现有 Origin 校验。

通常更新：开启维护排空，填写公告。在线玩家收到不抢焦点的底部状态条；新单人局、
新建房间及大厅开局被服务器拒绝，已开始的对局可以正常结算、同步。
点击刷新状态，等到“已排空，可更新容器”后执行部署脚本。
新版部署脚本也会检查排空状态；初次从 0.7.4 更新时，旧后端尚无此功能，需自行选择无人游玩时更新。
服务器重启保留维护开关；确认更新成功后，由管理员点击“重新开放服务器”。

“紧急更新”是另一个需确认的红色操作：全服倒计时 10 秒，结束当前对局，
按原游戏流程结算，等待存档同步后刷新。它不部署镜像、不下载代码，也不重启 NAS。
存在存档冲突、同步失败时，客户端保留当前页面与浏览器副本，不强行刷新。
取消/重新开放会取消尚未执行的紧急倒计时；已结束的对局不会恢复。
普通新版本仍等本局结束，不读取未经管理员授权的 `version.json.force`。
该机制需要玩家先安装一次支持此功能的客户端，旧页面不理解新消息。

排空统计来自服务器发出的单人/房主开局凭证及运行中房间。正常提交成绩或结束对局
释放凭证；已结算但仍在阅读战报的房间不会阻塞排空。未联网的浏览器离线超过 90 秒后清理遗留凭证，房间沿用 30 秒重连期限。
网页不可见但仍连接的对局不会仅因切后台被当成已完成。纯离线/访客游戏不计入服务器排空。

## 存档合并与经济保护

借鉴上游 `bd7f3dd` 的多设备同步目标，但**不移植 Firebase 账本、不相加余额快照**。
NAS 的 SQLite 事务、存档修订号和幂等 mutation ID 是提交边界。

- 返回主菜单、重新开始游戏及回到前台（非对局中）拉取最新存档。
- 浏览器先保留待提交副本；服务器用自身保留的历史修订作三方比较，
  不信任客户端提供的基础快照。
- 不涉及并行经济变化时，可合并收藏、异色、图鉴式解锁；统计取最大值而非重复累加。
  两边同时修改的普通偏好字段会提示冲突。
- 金币、券、强化/投入成本、保底、任务和成就奖励属于同一个经济分支。
  两台设备同时改动该分支时不自动合并；界面说明冲突，并列出金币、券、收藏数量，
  可以导出两份副本再明确选择。历史基础已过保留窗口（20 份）时也保留冲突。
- `economy_audit` 按账号/已接受修订记录金币、单抽券、十连券的增减及 mutation ID。
  同一 mutation 不会被重复入账；冲突回滚和存档、奖励收据、审计在同一事务内。
- 该功能不是新的完整反作弊系统。游戏原有奖励计算仍在浏览器执行；
  审计记录的是服务器接受的提交，不能证明每笔客户端收益的真实性。

## 同账号设备管理

设置 → 账号 → 查看设备：显示会话的浏览器标识、最近活动和当前设备。
不储存 IP、密码或完整设备指纹。公开 API 不返回原始会话令牌。
撤销指定/其他设备和接管需要再次验证账号密码，不删除任何账号、存档或浏览器副本。

账号已有在线对局时，新设备不会静默踢掉旧对局。新设备的开局、强化、提交受到保护；
可等待旧局结束，或明确确认接管。接管会断开原设备并退出其房间；原浏览器尚未
提交的进度继续保留，之后发生并行修改时仍需解决冲突。
撤销会话会立即断开对应 WebSocket，旧连接消息、后续 HTTP 请求均失效。
同一浏览器标签页共享 Cookie，因此列表表示浏览器会话，不把每个标签页冒充独立设备。

## 网络诊断与战报

诊断 JSON 格式 2：保留 NAS RTT、经 NAS 的队友探针 RTT、帧率、队列和重连指标，
另外列出实际选中的 WebRTC candidate-pair RTT、候选类型与 UDP/TCP 协议。
只输出白名单统计，不输出 IP、ICE SDP/candidate、UID、房间号、Cookie 或存档。
加载资源记录不含源站地址和 query，最多 64 条；传输字节、编码/解码体积、首字节、耗时、
HTTP 协议来自 PerformanceResourceTiming。体积差仅表明压缩，不能区分 gzip/Brotli；
缓存和浏览器未提供数据时不可把零字节当成网络丢包。WebRTC 不可用仍使用 NAS 中继。

团队战报由房主观测，直伤扣除护盾与溢出；直伤最后一击计击败，参与直伤后队友完成
击败计助攻；复活完成时附近存活的协助者计救援。环境/持续伤害没有可靠归属时不冒认。
战报通过现有可靠事件/状态通道同步，最终成绩验证成员及数值后存入 NAS，结算页显示。
数值不额外发钱、不改变难度、奖励或排行榜的原有排序，也不宣称服务器权威战斗判定。

## 验证边界

自动化使用临时数据库、独立 Chrome 上下文和实际本机 WebSocket/WebRTC；
浏览器注入伤害/复活场景只验证事件和统计链路，不代表真实跨国网络或物理手柄验收。
NAS 部署须执行更新命令；本地测试不修改线上账号或存档。
