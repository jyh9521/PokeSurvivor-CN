# 交互与渲染修订（0.6.0）

## 实施前代码结论

- 本项目是原生 JavaScript + DOM + Canvas 2D，不是 Godot；没有场景节点或引擎 Shader。
- 输入经过 Input、Gamepad、PadNav，再到 Game.handleKeys；已有原生相机随机偏移，尚无振动接口。
- UI.show 可保留主菜单；原焦点仅按 z-index 和 DOM 顺序选择，同层主菜单会抢走子页焦点。原焦点外框还会被滚动容器裁掉。
- 单项强化在 menu.js 扣币，批量强化在共享 Upgrades 扣币；旧存档只有 pupg 等级，没有逐笔成本。旧返还用当前价格重算并全额返还。
- 世界本来按脚底 Y 排序；新增的最顶层完整角色重绘破坏了树木遮挡，并把完整圆环画在角色身上。墙地形是烘焙的平面碰撞地块，没有独立高耸墙体或建筑场景；树、岩石、箱子、祭坛等是独立排序物体。

## 共用层与输入

UIFocus 以显式 `.scr` / `data-ui-layer`、CSS 层级和实际打开顺序确定唯一输入层。子层优先，关闭时恢复触发控件；重建控件可用 locale-neutral `data-focus-key` 恢复。收藏选择器也使用子层，确认框沿用 Dialog 队列与默认取消。

返回控件声明 `data-ui-back` / `data-back`；不在手柄代码中维护逐页面按钮 ID 表。键盘 Escape 与手柄 B 共用返回逻辑，强制选卡没有可返回操作时不会退出。Tab 限制在最上层。

LB/RB 对 `.tabs` / `.gen-tabs` / `.filters` 中真实可选分页生效，优先当前焦点所属组，否则第一组；边界停留，重建分页后焦点进入新选中标签。对局没有界面时仍切换招式。X 重抽通过 `data-pad-shortcut=2` 激活原按钮，不复制消耗逻辑。

键盘、点击、有效鼠标移动、滚轮恢复键鼠模式；按钮新按下或摇杆明显变化切回手柄。20% 移动死区和 35% 设备切换阈值分离；轻微漂移及静止保持的摇杆不会夺回输入提示。已打开页面每帧更新设备提示。键盘动作绑定现在由 Input.bindings 共用于运行逻辑及提示；目前产品没有用户自定义键位设置页面，没有新增重映射功能。

焦点在控件内部完整描边并改变背景，不依赖容易被裁掉的外边线；没有放大布局或修改鼠标悬停规则。

## 下拉列表

所有普通单选框共用视口级列表门户，原生 select 仍保存真实值并派发原 change 事件。列表不再交给操作系统原生弹出层在缩放滚动面板中排版；每次首次打开即计算可用空间、实际内容高度和滚动范围。支持窗口变化、根 UI 缩放、键盘、鼠标及手柄。手柄直接操作原 select 时仍采用 A 进入/提交、B 撤销预览。

## 奖励与强化

一键领取范围是全部已完成的每日和每周任务，与当前分类无关；逐个调用原 claim，先标记领取再发放，拒绝不属于当前任务集的对象。成就仍按原逻辑自动发奖，无需再次领取。

单项与批量强化均用共享 purchase，按每次实际扣除金额保存 `pspent[dex][upgradeId] = [costPerTier]`，NAS 单项购买也使用带存档版本检查的事务接口。返还按已保存金额总和的 50% 向下取整；支持单只或全部，清除对应等级、成本和招式禁用选择，不改变强化属性公式。返还清空后再次操作为零。已有未知历史等级字段保留。

**旧存档兼容规则**：0.5.0 未记录真实逐笔成本，使用冻结的 0.5.0 各级成本表补齐一次，之后保存账本；不会在返还时套用可变的新价表。缺失的原始账目不冒充存在。若外部修改过旧版本价格，旧数据没有足够信息还原那部分差异。新购买全部记录真实扣费。服务器验证账本结构、等级对应长度和金额范围；现有客户端进度信任模型保持不变，并不宣称具有服务器权威反作弊。

两个批量按钮移到强化页头部，宽屏横排、窄屏换行，返还为既有危险色。确认框显示 50% 和实际预计到账数；等级后缀使用 I18n 模板。

## 受击与遮挡

仅本地角色实际 HP 减少后触发反馈；类型免疫、无敌、零伤害、远端角色受击以及气势披带最终未扣血均不触发。相机复用已有偏移系统，损伤脉冲取最大值不累加，衰减归零且不修改跟随中心；保留其他相机特效与“减少震动”设置。

手柄双马达使用浏览器原生 vibrationActuator.playEffect，90–170ms，强度有上限；新效果覆盖旧效果，失焦、切回键鼠、断开或禁用手柄时 reset。未实现接口、调用拒绝或设备异常均忽略。

角色正常精灵与轮廓只在原 Y 排序位置绘制；脚底标记分为后半圆、角色、前半圆。顶层不再完整重绘角色。Occlusion 仅把前景物体的实际透明像素遮罩与角色帧相交，绘制最高 28% 透明可视层；重叠物体共用并集遮罩，不叠加角色不透明度。使用动画尺寸的缓存画布而非整屏离屏画布；同样适用于联机伙伴。原有天气、投射物、特效、HUD 顺序不变。
