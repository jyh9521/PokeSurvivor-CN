# 战斗重构 V2 — 阶段 B
父检查点：阶段A `a08068ed`。本阶段协议15，存档schema3，近战保护、普通HP/刷怪、永久购买与费用账本不变。

## 经验审计与取舍
基线与六轮候选均使用seed17、真实Spawner/AI/碰撞/掉落/拾取/原始三选一、自动驾驶的30分钟请求。死亡后终止，不补血/复活/预设未来等级；无强化的三个基线在382–538秒死亡，绝不把它们当作30分钟存活。满永久强化三种构筑都完成30分钟。当前版本的起始掉落为4.2→1.4，不混用历史截图倍率。

- B1/B2：早期经验需求1.25～2倍，部分近战中段升级间隔从47秒恶化到157秒；撤回。
- B3/B4/B5：测试不同时间掉落与较早的高等级需求加压。部分构筑出现末段完全无升级，未采用。
- B6采用：48级之前的XP需求完全保留；48/60/80级需求系数1/2/5，以smoothstep插值。落地XP倍率0/180/600/1200/1800秒为4.2/4.2/1.4/2.8/4.2；普通掉落只在生成时乘一次。五个野生Boss XP×2，裂隙既有奖励不变。永久智慧/道具只在拾取时乘一次；追赶关闭。
- 不因近战晚期KPS低就提高所有杂兵HP，或开启按DPS惩罚的刷新反馈。发现实际主要瓶颈是有限技能对积压敌人的清除/相性/组成，而非大量XP丢在地上：近战末段未拾取XP接近0，活敌常驻63。C/D须在相同驱动下继续验证，而非用经验补丁掩盖。

## 波次压制
`max(12*(1+t/600), maxHp*r(t))`；r在180/600/1200/1800秒为.08/.13/.18/.23，smoothstep连续；中性区域伤害不额外受幽灵对一般系抗性影响。有效特防65%只用于pressure，仍经过既有armor/(armor+180)、状态/近战减伤、格挡、护盾。半径68、预警1.8秒、8/16秒调度、64怪硬上限保留；独立1秒压制命中冷却阻止重叠标记连扣，普通接触无敌帧仍不能硬吃压制。

四种高HP/双防恢复、低防高速、远程、近战于3/10/20/30分钟各测四种护甲参与度，64个真实最终承伤样本；最终选择65%。例：502HP坦克30min单击17.75→51.91；仍仅损失10.34%，不是23%纯扣血。其完整恢复预算可在孤立区域攻击间回满，这是生存投入收益，不宣称压制单独必杀恢复构筑；持续站桩仍须承受敌人组合和危险区。移动脱离=0；同区及重叠不重复扣；纯伤害与普通特殊伤害未变。同步hz显式携带pressure，检查点包含冷却，协议15拒绝旧客户端。
