# NAS 联机频率与网络诊断（0.2.4）

## 同步与积压处理

NAS 不再冒用付费低速中继标志。正常目标频率是 15 Hz（约每 67 ms 一次）；浏览器发送积压或最近一次探测的 NAS 向本浏览器发送积压达到 64 KiB 时，目标降至 5 Hz，积压解除后恢复。计时器保留帧间剩余时间，避免受屏幕刷新率取整影响而长期低于目标。

浏览器和 NAS 共用 locale-neutral 的 js/net/relay-flow.js。只合并 k=f 且 ev 是空数组的状态帧，每个对端保留最新一帧，最多 4 个槽位。含道具、升级、敌人生成/消失、裂隙等事件的帧不会被当作纯状态丢弃；新事件发出后旧状态不能再倒序补发。队列按房间隔离，离开房间或更换成员后清理。达到硬上限会显式断开，浏览器使用 4008、服务端使用 1013，而不是偷偷丢弃事件。

## 玩家操作

登录后点击“联机诊断”，对局中也可打开；不会主动暂停游戏。

- 浏览器 ↔ NAS：认证 WebSocket 上的往返探测。
- 房间往返（经 NAS）：浏览器 → NAS → 另一位玩家 → NAS → 浏览器，包含另一浏览器处理时间；并非玩家直连延迟。
- 波动：最近至多 20 次 NAS RTT 的相邻差值平均值，不使用两台机器的墙上时钟。
- FPS：实际游戏动画帧回调频率，不是屏幕规格。
- 发送/接收频率：最近 2 秒内单连接的最大帧率；刚进入房间时等待窗口填满。
- 积压：本浏览器以及 NAS 向本浏览器发送的 WebSocket bufferedAmount。
- 探测超时：5 秒未响应的探测数量；不是实际网络丢包率。

探测约每 2 秒一次，只允许当前房间成员回声；每个成员的回声响应限频。所有探测复用已认证的 WebSocket，没有公开管理接口或额外端口。

“导出诊断”只保存格式版本、时间、延迟、FPS、频率及队列等数字指标。不导出 Cookie、账号名、用户 ID、IP、密码、存档或完整通信数据。邀请朋友在同一局、同一时间导出，可比较设备性能与跨境链路状况。

此阶段没有新增 WebRTC、STUN、TURN、云端中继或付费服务。账号、双份存档、百万金币一次性领取记录和玩家历史恢复禁用规则不变。修正同步频率不等于消除国内到日本的线路延迟。

## 测试

npm run test:nas 检查回声鉴权、队列合并/顺序、房间边界、硬限制、单调时钟 RTT、超时和有界槽位，并保留原有存档/福利/联机回归。npm run test:nas:browser 测量真实两浏览器通过 NAS 的数据帧率与往返探测，再检查原联机和裂隙修复。npm run test:nas:production 检查保护包、诊断导出隐私及手机布局。

本地受控浏览器测试不代表已完成国内到日本的公网验收。更新命令仍使用 deploy/update-unraid.sh，保留原 /data；请先结束当前对局，并让所有玩家刷新到新版本。
