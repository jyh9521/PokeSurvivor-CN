# 手柄操作与验证（0.6.0）

## 输入与按键

使用原生标准 Gamepad API，不引入运行时依赖。连接后先按下并松开一次按钮；使用第一个 `mapping=standard` 的设备。按实体位置理解以下按键，设备按键文字会自动识别，也可在设置 → 操作 → 手柄按键样式选择 Xbox / PlayStation / Nintendo。

|实体位置|Xbox|PlayStation|Nintendo|用途|
|---|---|---|---|---|
|下方按钮|A|×|B|确认；对局中集合|
|右方按钮|B|○|A|返回 / 取消；不从战斗打开暂停|
|左方按钮|X|□|Y|联机求救；选卡时重抽|
|上方按钮|Y|△|X|联机危险标记|
|左右肩键|LB / RB|L1 / R1|L / R|对局切换招式；菜单切换适用分页|
|菜单键|Start|Options|+|对局暂停 / 继续|

左摇杆或十字键移动。摇杆死区 20%，轻推慢走，斜向不加速；攻击仍自动进行。
Start 不跳过确认弹窗、选卡或设置；B 从暂停页返回即继续游戏，但战斗中按 B 不会打开暂停。

## 菜单与选择

- 按控件当前屏幕矩形的真实位置选上下左右邻居，不按 DOM 顺序走，不在边缘循环到另一侧；响应式布局变化后重新计算。
- 聚焦后滚动到可见区域；渲染替换节点后按 ID / 属性或原位置恢复焦点。隐藏、禁用、锁定与已完成的卡牌不参与导航。
- 下拉框：确认键进入编辑，方向键预览选项，确认键提交；返回键取消，恢复原值。避免弹出浏览器原生选择器。
- 滑条：左右调整数值，上下离开；复选框与开关由确认键切换。
- 菜单顶部设置、声音、资料和弹窗关闭按钮可以导航；设置、资料、新闻、法律说明、邀请和网络面板优先捕获操作，防止点到后方页面。
- 等级 / 道具 / 羁绊选择不可用 B 跳过；羁绊第二步可返回第一步。重抽使用左侧面键，也可以聚焦重抽按钮确认。
- 账号、密码、昵称和搜索等文字输入仍使用键盘；输入完成后可用手柄移动到提交按钮。

## 游戏内确认弹窗

原生确认框改为 `G.Dialog` 异步游戏内对话框：默认聚焦取消，按实际位置选择确认，B 取消。Tab 限制在弹窗内，Esc 取消并阻止传递到后方页面；关闭后恢复之前焦点。
涵盖退出游客、强化返还、删除好友、成绩举报和账号删除；密码验证使用同一套对话框，密码输入是文字输入例外。自动更新会等待对话框关闭。
不把 `window.confirm` 替换为返回 Promise 的函数，避免旧同步条件误判。

## 提示与设备

实际操作手柄时显示手柄按钮：选中卡牌确认键、重抽键、暂停页、技能栏及联机标记均随设备变化；鼠标 / 键盘操作后恢复原提示。手柄样式覆盖只保存在当前浏览器设置，不改变账号或存档。
受击时使用原生双马达振动；没有振动接口的设备正常忽略。右摇杆、扳机及自定义重映射未新增。详细的层管理、35% 设备切换阈值和测试边界见 INTERACTION.md。浏览器的初始音频 / 全屏权限仍由浏览器控制。

## 复现

```sh
npm run test:nas
node tests/gamepad-browser.cjs
node tests/playability-browser.cjs
npm run test:nas:browser
npm run test:nas:production
node tools/verify-gamepad-transaction.cjs
```

几何算法的 Node 测试独立于 DOM 顺序；真实 Chromium 测试使用可控标准手柄数据，覆盖真实界面、移动与保存，并非 Xbox / DualSense / Switch Pro 实物验收。
